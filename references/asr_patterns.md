## 酒店测评 / vlog 转写碎条（Rosewood Bangkok 曼谷瑰丽，582 条）
- 片源：两人（女旁白 + 伴侣 Oscar）测评曼谷瑰丽酒店，两晚 595 美元，2001 房；结尾给总分 65/100。
- **碎条特征（本片核心难点）**：时间码 1–2 秒一条，句子常被切在**相邻两条**，改 EN 必须按条目保留断句、不得合并：
  `#51 "…our room light and curtain"` / `#52 "controls."`；`#101 "…Japanese toilets, but at"` / `#102 "least they have a bum gun."`；
  `#437`/`#438`、`#528`/`#529` 同理。跨条目承接还会触发中文漂移（`#164 "while I"` / `#165 "opened the soap."`）——

## 63. 平台「违禁词」复查（抖音上传被拦后的补救）——He Has 8 MICHELIN STARS 1201 条（2026-11-01）

同一条片子上传抖音时被提示「有违禁词」。复盘后发现：**之前的合规版只处理了「平台名/频道」两类，
把「广告法极限词 + 暴力血腥 + 诱导互动」整块漏了**。这是 62 节之后必须补上的一课。

### 一、双语烧制是最大的坑
目录里有 `ass_debug.log` + `_bilingual.mp4` —— 烧制工具是「中文在上、英文在下」双语。
**上排中文过了审，下排英文照样会被 OCR 检出**：
`subscribe`（3 处 / #666 #1188 #1199）、`Instagram`（#1189）、`YouTube`（#442）、
`kill`（#429）、`weapon`（#510）、`Bloody Mary`（#584）。
→ 结论：**双语视频必须中文、英文两份都做合规版**（本项目新增 `_en_douyin.srt`）。

### 二、抖音中文侧必须清的四类词（按危险度排序）
1. **广告法极限词**：最 / 第一 / 世界级 / 完美 / 顶级 / 极致 / 唯一 / 绝对 / 冠军 / 王牌
   - 本项目实测 **「最」37 处 + 「第一」14 处 + 「完美」6 处 + 「世界级」1 处**，全片扫出 98 个待处理条目。
   - 注意区分：**「最后/最近/最南边/最适合」这类不是广告绝对化表述，但机审按字面拦**，
     为稳妥一律改（最后→收尾/结尾，最近→前几天，最南边→更南边，最短→起步）。
   - 「第一」几乎都是序数（第一道、第一次、第一波），改成 **「头」** 最自然：头一道、头一次、头一波。
2. **暴力血腥**：杀 / 血 / 血腥 / 武器 / 枪 / 死 / 暴 / 尸
   - 「我可以为它杀人」→「我可以为它豁出去」；「血腥玛丽」→「番茄鸡尾酒」；
     「让你选武器」→「让你挑工具」；「意大利血统」→「祖上来自意大利」；「粗暴的苦」→「生硬的苦」。
   - ⚠️ **「金枪鱼」含「枪」不算违规**，别误改。
3. **诱导互动**：关注 / 点关注 / 点赞 / 双击 / 订阅 / 粉丝团
   - 片尾求关注整段建议**直接剪掉**，字幕改成「下次再来」「也欢迎来餐厅」。
   - 「1,600 个关注者」→「1,600 个粉丝」（描述数据不算诱导，但要避开「关注」二字）。
4. **绝对化承诺**：免费 / 100% / 零添加 / 国家级 / 独家 / 首创
   - 「知识不是免费的」→「知识不是白来的」。

### 四、流程教训
- 合规改写 = 「平台名」+「极限词」+「暴力血腥」+「诱导互动」+「绝对化承诺」五类一起过，
  只过第一类是历史遗留问题，会在上传时被打回。
- 改写后必须用**独立的风险词表再扫一遍**（不能只信 `verify_srt.py` 的 banned 列表，
  它只覆盖平台名/链接）。
