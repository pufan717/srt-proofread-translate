# 国内自媒体合规替换表（抖音 / 视频号 / B站 / 小红书通用）

> 用于生成 `<视频名>_zh_douyin.srt`。**在翻译阶段同步完成，不事后补救。**
> 铁则：只改需要改的条目，**时间码与条目数完全不变**。

---

## 0. 先记住三条硬规则

1. **扫描器不看语境**。`verify_srt.py` 对 `订阅 / 频道 / 赞助 / 广告 / 链接` 做全文匹配，描述性、非推广的用法同样 FAIL。
2. **一个字都不能留**。用中性同义词替换，**不是删句子**——删句子会破坏语气，还可能让中文过短触发漂移告警。
3. **跨条句子两条同改**。一句被 ASR 切成两条时，禁用词常常落在**前一条**的译文里。

## 1. 境外平台名 → 泛化

| 原文 | 合规写法 |
|---|---|
| YouTube | 视频平台 |
| Netflix | 视频平台 / 追剧平台 |
| Instagram | 社交应用 / 图片应用 |
| Facebook | 社交应用 |
| TikTok | 短视频平台 |
| Twitter / X | 社交平台 |
| WhatsApp | 聊天软件 |
| Chrome | 浏览器 |
| Google Play | 应用商店 |
| Booking.com | 旅游网站 |
| Discord | 社群 |
| Substack | 专栏 |
| Patreon | 会员平台 |
| Amazon | 购物平台 / 电商平台 |

## 2. 订阅 / 频道 / 导流

| 原文 | 合规写法 |
|---|---|
| 订阅（频道） | 关注 |
| 订阅制 | 按月收费 |
| 频道（`on the channel` / `my channel`） | 账号 / 主页 |
| Newsletter（邮件订阅） | 推送 / 邮件通知 |
| 链接在简介里（`links in the description`） | 官网地址我放在下方文字说明里 |
| description | **文字说明**（「简介」本身也在边缘，一并换掉） |
| 个人网站 / 二维码 | 删除或泛化为「主页」 |
| 海淘店铺名 | 海淘渠道 |
| FedEx 等物流名 | 国际物流 |

> 实例（GTA6 #246）：原文 `scan the QR code and sign up for their newsletter`
> → 「上他们官网，注册邮件通知」（二维码 + 邮件订阅两处一起换）

## 3. 商业推广话术 → 自费口径

| 原文 | 合规写法 |
|---|---|
| 厂商送测（sent me this） | 自己购买 / 自购 |
| 赞助商（sponsor） | **合作伙伴** |
| 赞助段落（sponsored segment） | 合作段落 |
| 赞助（sponsored by） | 支持 / 由…支持 |
| 广告（advertisement） | 推广内容 / 个人分享 |
| 广告牌（billboard，描述性） | **灯箱屏幕** |
| 合作推广 | 自费体验 |
| 优惠码 / 折扣码 | 删除 |
| 广告收入 | 推广收入 |

> 关键区分：**「赞助」不只是商业话术，描述性用法（这期节目有赞助段落）同样要换。**
> 唯一安全的做法是全篇不留这四个字（订阅/频道/赞助/广告）。

## 4. 其他

- **导流链接**（含 `http` / `www.` / `.com`）：一律删除
- **应用商店引用**：泛化为「应用商店」或删除
- **境外酒店/餐厅预订渠道**：泛化为「官网」或删除
- **`中国香港` / `中国台湾` / `中国澳门`**：正确表述，**保留不改**

## 5. 执行与自检

翻译时直接写出合规文本，最后跑一次扫描确认合规版无残留：

```
python scripts/verify_srt.py "<视频名>.srt"
```

`verify_srt.py` 第 5 节会自动扫描以下禁用词并报 FAIL：

```
youtube, youtu, instagram, tiktok, facebook, twitter, netflix, amazon,
google play, discord, substack, patreon, newsletter, http://, https://,
www., .com, 订阅, 频道, 赞助, 广告, 链接
```

同时会打印 `[INFO] 合规改写条目数`，便于核对改动范围（**应当只改动少数条目，不是全篇重写**）。

写 DY_OVR 的 key 之前，先跑：
```
python scripts/process_template.py --keys      # 逐条 EN + ZH，确认禁用词真的落在那一行
```
verify 报残留时，输出的条目号就是真实落点，按它改，不要再猜。

## 6. 判断原则（拿不准时）

1. **可能被判定为「站外导流」的**：删或泛化
2. **可能被判定为「未申报商业推广」的**：改成自费口径
3. **纯粹提到某个境外平台作为内容本身**（如「我在某平台看了个视频」）：泛化为「视频平台」即可，不必删句子
4. **地名与政治表述**：按官方口径，香港/澳门/台湾均加「中国」
5. 改动越少越好——合规版与正常版应当高度一致，只有少数条目不同
6. **宁泛化不删句**：删句会让中文变短、触发漂移告警，也会让语义断裂
